РЕЖИМ.УСТАНОВКИ

PROD — сервер с доменом и SSL. LOCAL — localhost / WSL / тест.

A-запись DNS должна указывать на IP сервера до запуска SSL.

Для уведомлений Let's Encrypt о сроке сертификата.

POSTGRESQL
БЕЗОПАСНОСТЬ

ADMIN_KEY — доступ к админ-API. JWT_SECRET — сессии входа.

Срок жизни JWT-сессии в секундах (604800 = 7 дней).

Доп. защита /satana. Секрет из приложения-аутентификатора.

УЧЁТНАЯ ЗАПИСЬ

LOCAL: email и пароль для входа в Studio.

PROD: email для уведомлений. Вход — через OAuth / регистрацию.

TELEGRAM

Бот для DSL и уведомлений. @BotFather → /newbot → скопируйте токен.

EMAIL.RESEND

Письма (верификация, сброс пароля). resend.com/api-keys

Домен должен быть верифицирован в Resend.

CRYPTOBOT

Crypto Pay API. @CryptoBot → Crypto Pay → Create App → API Token.

GOOGLE.OAUTH

Вход через Google. Google Cloud Console → OAuth client ID (Web).

AI.STUDIO / DSL

Anthropic: console.anthropic.com

Groq: console.groq.com/keys

OLLAMA_URL / OLLAMA_MODEL:

ESPHOME

Сборка прошивок /esphome на сервере (.venv-esphome).
